What happened
1 · Mandate

The owner reviewed the task, typed the mission ID and signed a mandate naming the task, both agents, the model, a 2.00 USD cost cap and a 60-minute window.

2 · Agent A

EVE admitted agent A with exactly the task file. A produced a quote: 96 362.50 SEK including VAT, two requests left unpriced as questions.

3 · Handoff

Before agent B started, EVE checked that the package for B held A's output unchanged, the same task and nothing else.

4 · Agent B

EVE admitted agent B, who reviewed the quote and answered VERDICT: ACCEPT. A replay of the closed handoff was refused.

What this package does not establish
  • No independent verification, external audit or certification. The same producer built and checked the run. No external time anchor.
  • G-1 not performed: the mandate signature has not yet been checked against a published owner key. A prepared check, g1/G1_CHECK.sh, is included. A pass would prove that the signature matches the key, not who controls the key.
  • G-2 not resolved: the run client, server script and chain verifier named in the mandate are not in the package, so the chain checks cannot be re-run from it.
  • The agents' runtime tools and network egress were not established. No network isolation, production safety or hard cost limit is claimed.

Why 46 files in the package and 48 in the manifest
The 48 are the original files frozen from the run. The 46 are the files in the published package. They overlap in 39 files.
  • 39 originals are distributed byte-identical.
  • 9 originals are withheld: the main result record (server firewall state and signing detail), the run wrapper script, four isolation-window logs and the environment precheck (server addresses, owner environment, container topology), and two files that are replaced by redacted reading copies. Their names, SHA-256 and the reason for withholding are listed below.
  • The package adds 7 files that are not originals: the frozen manifest itself, the 2 reading copies, README.md, VERIFY_PACKAGE.py, g1/G1_CHECK.sh and PUBLICATION_MANIFEST.json.
39 + 7 = 46. A reading copy is never evidence: it carries its own hash and cannot be checked against the frozen manifest.
